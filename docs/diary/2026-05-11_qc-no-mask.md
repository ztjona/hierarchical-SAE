# 2026-05-11 — `QuartoCNNUnifiedNoMask` (QC, Q-series start)

**Status:** code landed; first run (`QC_unifiedNoMask(1)0511`) pending.

## Rationale

The M/N/O series have plateaued near 66–73% WR while the `games-interp`
audit on `AA(2)` identified two structural defects of the trunk:

1. The network does **not** learn cell legality
   (Test D Q-gap = −0.47 mean; legality is enforced entirely by the
   bot's inference-time validity filter).
2. `fc1` destroys the threat features that `conv2` still carries
   (LP F1 collapses 0.50 → 0.02 across the fc1 bottleneck).

QC targets both without changing the RL algorithm.

## Changes on top of the Unified-Aux trunk

QC extends the contract in
[`2026-05-08_unified-aux-trunk.md`](2026-05-08_unified-aux-trunk.md):
same 32-d phase-stable aux `[offered_one_hot ; available_pieces_mask]`,
same `state_aux` / `next_state_aux` keys, same `unified_autoreg`
transition schema, same target machinery
(`DQN_training_step_decoupled_autoreg`).

Three additive changes:

1. **Wider `fc1`** — `n_neurons = 256` instead of 128. Cheap capacity
   check on the bottleneck where threat features were getting lost.
2. **Auxiliary legality head** — `fc_aux_legality: Linear(256, 16)`,
   exposed via `forward_with_aux(...)` and `legality_logits(...)`,
   supervised every batch with `BCEWithLogits` against
   `legality_target_from_board(x_board)` (a free helper in
   `models/CNN_unified_nomask.py` returning 1.0 for empty cells in
   row-major order matching `Q_place`). Starting weight λ = 0.05.
3. **No inference legality mask.** The companion bot
   `bot/CNN_unified_nomask_bot.py` picks `argmax(Q_place)` directly;
   if the top-ranked cell is invalid it falls back to the next valid
   rank (so training can complete) and records `invalid_argmax_rate`
   as the legality-learning metric. The success criterion is that this
   rate → 0 over training, *not* zero from epoch 1.

## Training-loop integration

Inside the per-batch loop, after the existing `DQN_training_step` call:

```python
qp, qs, leg_logits = policy_net.forward_with_aux(state_board, state_aux)
leg_target = legality_target_from_board(state_board)
loss = dqn_loss + LAMBDA_LEGALITY * BCEWithLogitsLoss()(leg_logits, leg_target)
loss.backward()
```

`forward_with_aux` reuses the trunk activations; the auxiliary head
back-propagates through `fc1`, which is the whole point.

## Backwards compatibility

No existing class was modified.

- `Quarto_unified_bot` and `QuartoCNNAutoregUnified` continue to drive
  the OA series without seeing any QC code.
- All prior checkpoints (MA, MB, MC, MD, ME, MF, OA) still load and
  play.
- `decoupled_autoreg` / `joint` schemas are unchanged.

## Triplet-contract registration

Add QC to the `unified_autoreg` row of the schema × model × bot table:

| Schema | Model | Bot |
|---|---|---|
| `joint` | `QuartoCNN*` | `Quarto_bot` |
| `decoupled_autoreg` | `QuartoCNNAutoreg*` | `Quarto_autoreg_bot` |
| `unified_autoreg` | `QuartoCNNAutoregUnified*` | `Quarto_unified_bot` |
| `unified_autoreg` | `QuartoCNNUnifiedNoMask` | `Quarto_unified_nomask_bot` |

Mixing rows silently produces wrong aux semantics. The QC training
loop additionally requires `policy_net.legality_logits(...)` to exist
on the model, which restricts the bottom row to `QuartoCNNUnifiedNoMask`.

## Validation

`tests/test_qc_unified_nomask.py` covers the legality-target helper
(empty / half-full / row-major / bad-shape), `forward` shapes and tanh
range, `forward_with_aux` three-tuple, `legality_logits` shape, aux-dim
validation, numpy input acceptance, state-dict round-trip, and
`q_values_phase` routing. All 14 cases pass.

## Run plan and decision gate

See `Research-status.md` → `QC_unifiedNoMask` for the pre-registered
decision gate (WR vs `bot_random` ≥ 95%, WR vs `ME_endgame(2)_E_5000`
≥ 50%, `invalid_argmax_rate` < 0.05 over last 100 epochs) and the
Q-series roadmap (Q3 select-reward shaping, Q4 extended N curriculum).

QC(1) is a **single from-scratch run**, not a sweep, deliberately —
the architecture must clear the decision gate before spending compute
on parameter sweeps over `ENDGAME_FRACTION` or `λ_legality`.
